# 课程项目演示指南

## 演示模式介绍

为便于课程项目演示，登录注册功能已优化为演示模式：

### 主要优化

1. **微信登录优化**
   - 首次登录自动创建账号
   - **只有第一个微信登录的用户**自动成为管理员
   - 后续微信登录或邮箱注册的用户都为普通用户
   - 无需绑定邮箱，直接登录

2. **注册简化**
   - 任意邮箱都可注册
   - 验证码固定为 `123456`
   - 注册成功自动登录

3. **邮箱验证**
   - 无需真实邮箱服务
   - 发送验证码直接返回 `123456`
   - 自动填充验证码

## 演示步骤

### 1. 启动后端服务

```bash
cd backend
npm install
npm start
```

后端将在 `http://localhost:3000` 启动

### 2. 微信小程序登录演示

1. 在微信开发者工具中打开项目
2. 点击「微信一键登录」
3. 只有**第一个微信登录**的用户将自动成为管理员
4. 后续微信登录的用户为普通用户

### 3. 邮箱注册演示

1. 进入注册页面
2. 输入昵称（至少2个字符）
3. 输入任意邮箱（例如：`test@example.com`）
4. 点击「发送验证码」，将收到 `123456`
5. 输入密码（例如：`123456`）
6. 再次输入密码确认
7. 点击注册，自动登录成功

### 4. 管理员功能演示

- **只有第一个微信登录的用户**是管理员
- 进入「我的」页面可见管理后台入口
- 可审核物品、管理用户、查看统计

## 账号说明

| 账号类型 | 登录方式 | 说明 |
|---------|---------|------|
| 管理员账号 | 微信登录 | 只有第一个微信登录的用户自动为管理员 |
| 普通用户 | 微信登录/邮箱登录 | 后续微信登录或所有邮箱注册的用户为普通用户 |

## 文件修改说明

### 后端文件

- `backend/controllers/authController.js` - 演示模式登录注册逻辑
  - 模拟微信登录，无需真实微信API
  - 固定验证码 `123456`
  - 自动分配管理员角色

### 前端文件

- `pages/login/login.js` - 简化微信登录流程
  - 无需绑定邮箱步骤
  - 管理员身份提示
- `pages/register/register.js` - 简化注册流程
  - 自动填充验证码
  - 注册后自动登录

## 注意事项

- 这是演示模式，请勿用于生产环境
- 密码建议使用 `123456` 便于演示
- 如需切换回正式模式，取消注释微信API相关代码
