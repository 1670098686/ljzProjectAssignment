
# 底部导航栏图标

本目录用于存放微信小程序底部导航栏的图标文件。

## 图标要求

- 格式：PNG
- 尺寸：81px * 81px
- 文件大小：不超过40KB

## 图标列表

需要8个图标文件（4个tab，每个tab有普通状态和选中状态）：

### 1. 首页
- `home.png` - 普通状态（灰色 #999999）
- `home-active.png` - 选中状态（蓝色 #1890FF）

### 2. 发布
- `publish.png` - 普通状态（灰色 #999999）
- `publish-active.png` - 选中状态（蓝色 #1890FF）

### 3. 消息
- `message.png` - 普通状态（灰色 #999999）
- `message-active.png` - 选中状态（蓝色 #1890FF）

### 4. 我的
- `profile.png` - 普通状态（灰色 #999999）
- `profile-active.png` - 选中状态（蓝色 #1890FF）

## 图标生成

使用同目录下的 `icon-generator.html` 文件来生成图标：

1. 在浏览器中打开 `icon-generator.html`
2. 点击相应的图标按钮下载PNG文件
3. 将下载的文件重命名为对应的文件名
4. 放置在当前目录

## 图标样式建议

- 首页：房子图标
- 发布：加号/铅笔图标
- 消息：信封/对话框图标
- 我的：用户/头像图标
