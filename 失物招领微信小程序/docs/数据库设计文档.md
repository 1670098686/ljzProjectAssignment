# 校园失物招领小程序 - 数据库设计文档

## 1. 数据库概述

- **数据库名称**：`lost_and_found`
- **数据库版本**：MySQL 8.0+
- **字符集**：utf8mb4
- **排序规则**：utf8mb4_unicode_ci
- **存储引擎**：InnoDB

## 2. 数据表设计

### 2.1 用户表 `users`

存储系统所有用户（含管理员）的基本信息。

| 字段 | 类型 | 必填 | 默认值 | 描述 |
|------|------|------|--------|------|
| `id` | INT | 是 | AUTO_INCREMENT | 主键 |
| `openid` | VARCHAR(64) | 否 | NULL | 微信 openid |
| `unionid` | VARCHAR(64) | 否 | NULL | 微信 unionid |
| `email` | VARCHAR(128) | 否 | NULL | 学业邮箱 |
| `password` | VARCHAR(255) | 否 | NULL | bcrypt 哈希后的密码 |
| `nickname` | VARCHAR(64) | 否 | NULL | 昵称 |
| `avatar_url` | VARCHAR(255) | 否 | NULL | 头像 URL |
| `role` | ENUM('USER', 'ADMIN') | 是 | 'USER' | 用户角色 |
| `phone` | VARCHAR(32) | 否 | NULL | 手机号 |
| `signature` | VARCHAR(200) | 否 | NULL | 个性签名 |
| `email_verified` | TINYINT(1) | 否 | 0 | 邮箱是否已验证 |
| `status` | TINYINT(1) | 否 | 1 | 账号状态（1正常/0禁用） |
| `created_at` | TIMESTAMP | 是 | CURRENT_TIMESTAMP | 创建时间 |
| `updated_at` | TIMESTAMP | 是 | CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**索引**：
- 主键：`PRIMARY KEY (id)`
- 唯一键：`uk_openid (openid)`
- 唯一键：`uk_email (email)`

### 2.2 邮箱验证码表 `email_verification_codes`

存储邮箱验证码，用于注册、找回密码等场景。

| 字段 | 类型 | 必填 | 默认值 | 描述 |
|------|------|------|--------|------|
| `id` | INT | 是 | AUTO_INCREMENT | 主键 |
| `email` | VARCHAR(128) | 是 | - | 接收邮箱 |
| `code` | VARCHAR(10) | 是 | - | 验证码 |
| `purpose` | ENUM('REGISTER', 'RESET_PASSWORD', 'BIND_EMAIL') | 是 | - | 用途 |
| `expires_at` | TIMESTAMP | 是 | - | 过期时间 |
| `used` | TINYINT(1) | 否 | 0 | 是否已使用 |
| `created_at` | TIMESTAMP | 是 | CURRENT_TIMESTAMP | 创建时间 |

**索引**：
- 主键：`PRIMARY KEY (id)`
- 普通索引：`idx_email (email)`
- 普通索引：`idx_expires (expires_at)`

---

### 2.3 物品信息表 `items`

存储寻物启事和拾物招领信息。

| 字段 | 类型 | 必填 | 默认值 | 描述 |
|------|------|------|--------|------|
| `id` | INT | 是 | AUTO_INCREMENT | 主键 |
| `user_id` | INT | 是 | - | 发布者用户 ID |
| `item_type` | ENUM('LOST', 'FOUND') | 是 | - | 信息类型（寻物/拾物） |
| `title` | VARCHAR(128) | 是 | - | 标题 |
| `category` | VARCHAR(32) | 是 | - | 分类 |
| `happen_time` | TIMESTAMP | 是 | - | 遗失/拾获时间 |
| `location` | VARCHAR(128) | 是 | - | 地点 |
| `feature_desc` | TEXT | 否 | NULL | 详细特征描述 |
| `contact_name` | VARCHAR(64) | 否 | NULL | 联系人姓名 |
| `contact_phone` | VARCHAR(32) | 否 | NULL | 联系电话 |
| `contact_wechat` | VARCHAR(128) | 否 | NULL | 微信号 |
| `audit_status` | ENUM('PENDING', 'APPROVED', 'REJECTED') | 否 | 'PENDING' | 审核状态 |
| `biz_status` | ENUM('ONGOING', 'RESOLVED', 'RETURNED', 'CANCELLED') | 否 | 'ONGOING' | 业务状态 |
| `view_count` | INT | 否 | 0 | 浏览次数 |
| `is_locked` | TINYINT(1) | 否 | 0 | 是否被管理员锁定 |
| `visible` | TINYINT(1) | 否 | 1 | 是否可见（0下架/1上架） |
| `published_at` | TIMESTAMP | 否 | NULL | 发布/通过审核时间 |
| `created_at` | TIMESTAMP | 是 | CURRENT_TIMESTAMP | 创建时间 |
| `updated_at` | TIMESTAMP | 是 | CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**索引**：
- 主键：`PRIMARY KEY (id)`
- 普通索引：`idx_user (user_id)`
- 普通索引：`idx_type (item_type)`
- 普通索引：`idx_audit (audit_status)`
- 普通索引：`idx_biz (biz_status)`
- 普通索引：`idx_happen_time (happen_time)`
- 普通索引：`idx_published (published_at)`
- 全文索引：`idx_search (title, location, feature_desc)`

**外键**：`FOREIGN KEY (user_id) REFERENCES users(id)`

**业务状态流转规则**：
- LOST 类型：ONGOING → RESOLVED / CANCELLED
- FOUND 类型：ONGOING → RETURNED / CANCELLED
- 终态（RESOLVED/RETURNED/CANCELLED）不可回退

### 2.4 物品图片表 `item_images`

存储物品的多张图片。

| 字段 | 类型 | 必填 | 默认值 | 描述 |
|------|------|------|--------|------|
| `id` | INT | 是 | AUTO_INCREMENT | 主键 |
| `item_id` | INT | 是 | - | 物品 ID |
| `image_url` | VARCHAR(255) | 是 | - | 图片 URL |
| `sort` | INT | 否 | 0 | 排序（越小越靠前） |
| `created_at` | TIMESTAMP | 是 | CURRENT_TIMESTAMP | 创建时间 |

**索引**：
- 主键：`PRIMARY KEY (id)`
- 普通索引：`idx_item (item_id)`

**外键**：`FOREIGN KEY (item_id) REFERENCES items(id) ON DELETE CASCADE`

---

### 2.5 会话表 `conversations`

用户之间针对某物品发起的对话会话。

| 字段 | 类型 | 必填 | 默认值 | 描述 |
|------|------|------|--------|------|
| `id` | INT | 是 | AUTO_INCREMENT | 主键 |
| `user1_id` | INT | 是 | - | 用户1 ID |
| `user2_id` | INT | 是 | - | 用户2 ID |
| `item_id` | INT | 否 | NULL | 关联物品 ID |
| `last_message_at` | TIMESTAMP | 否 | NULL | 最后一条消息时间 |
| `created_at` | TIMESTAMP | 是 | CURRENT_TIMESTAMP | 创建时间 |
| `updated_at` | TIMESTAMP | 是 | CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**索引**：
- 主键：`PRIMARY KEY (id)`
- 唯一键：`uk_user_pair_item (user1_id, user2_id, item_id)`
- 普通索引：`idx_user1 (user1_id)`
- 普通索引：`idx_user2 (user2_id)`
- 普通索引：`idx_last_message (last_message_at)`
- 普通索引：`idx_item (item_id)`

**外键**：
- `FOREIGN KEY (user1_id) REFERENCES users(id)`
- `FOREIGN KEY (user2_id) REFERENCES users(id)`
- `FOREIGN KEY (item_id) REFERENCES items(id)`

---

### 2.6 消息表 `messages`

会话中的聊天消息。

| 字段 | 类型 | 必填 | 默认值 | 描述 |

## 4. 索引优化说明

| 表 | 索引 | 使用场景 |
|----|------|----------|
| users | uk_openid, uk_email | 登录/注册时的快速查找 |
| items | idx_user | "我的发布"列表查询 |
| items | idx_type + idx_audit | 首页按类型+审核状态筛选 |
| items | idx_biz | 按业务状态过滤 |
| items | idx_search (FULLTEXT) | 标题/地点/描述的全文搜索 |
| conversations | uk_user_pair_item | 防止重复创建同一对话 |
| messages | idx_conversation + idx_created | 会话消息分页查询 |
| notifications | idx_user + idx_read | 未读通知数量统计 |
| reports | idx_status + idx_handler | 管理员按状态/处理者筛选举报 |
| audit_logs | idx_item | 查看某物品的审核历史 |

## 5. Redis 缓存使用说明

项目同时使用 Redis 作为缓存层，主要缓存：

| 键名模式 | 用途 | 过期时间 |
|----------|------|----------|
| `code:{email}:{purpose}` | 邮箱验证码 | 5分钟 |
| `rate_limit:{ip}:{endpoint}` | 接口限流 | 1分钟 |
| `user_profile:{user_id}` | 用户基本信息 | 1小时 |
| `token_blacklist:{token_uuid}` | 已吊销的 token | token 有效期 |

## 6. 初始化数据

启动时可插入一条默认管理员账号，`role='ADMIN'`，密码需使用 bcrypt 哈希值。生产环境请务必修改并限制此账号的登录策略。
