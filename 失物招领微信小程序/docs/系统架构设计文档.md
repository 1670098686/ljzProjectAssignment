# 校园失物招领小程序 - 系统架构设计文档

## 1. 整体架构概述

本项目采用**前后端分离**架构，分为两个独立应用：

- **前端**：微信小程序原生开发（WXML / WXSS / JavaScript），直接运行于微信客户端
- **后端**：Node.js + Express 框架，提供 RESTful API 服务
- **数据库**：MySQL 8.0 持久化存储 + Redis 缓存/限流
- **文件存储**：本地文件系统（uploads 目录）

架构分层清晰，通过 HTTPS 通信，后端统一提供 JSON 响应。

## 6. 统一响应与错误处理

所有接口返回统一 JSON 结构：

```json
{
  "code": 0,
  "message": "success",
  "data": { ... },
  "requestId": "uuid",
  "timestamp": "ISO8601"
}
```

错误处理策略：
- **400 参数错误**：express-validator 校验失败，返回具体字段错误
- **401 未登录**：token 无效或已过期，引导重新登录
- **403 无权限**：普通用户访问管理员接口、非本人编辑他人信息
- **404 资源不存在**：物品/用户/会话 ID 不存在
- **409 冲突**：重复审核、邮箱已注册等
- **429 限流**：接口请求过于频繁
- **500 内部错误**：未捕获异常，记录 requestId 方便排查

## 7. 安全策略

| 维度 | 实现方式 | 所在位置 |
|------|----------|----------|
| 认证 | JWT (accessToken 短生命周期) + refreshToken | middlewares/auth.js、controllers/authController.js |
| 密码 | bcryptjs 单向哈希（salt rounds = 10） | controllers/authController.js |
| SQL 注入 | 所有查询使用参数化 SQL，禁止字符串拼接 | models/*.js |
| 输入校验 | express-validator 进行字段长度/格式验证 | controllers/*.js |
| 限流 | Redis 计数器实现接口限流（登录、验证码、消息） | 路由层 + controller 入口 |
| 权限校验 | 管理员接口强制校验 role=ADMIN | middlewares/auth.js 的 requireAdmin |
| 数据归属 | 编辑/删除操作检查 userId 匹配当前登录用户 | controllers/itemController.js |
| 状态校验 | bizStatus 终态不可回退；已审核不可重复审核 | models/Item.js + controller 检查 |
| 文件上传 | 限制文件类型（jpg/png/gif）、大小（单张 5MB） | controllers/fileController.js + multer 配置 |
| 请求追溯 | 每个请求分配唯一 requestId，写入响应和日志 | middlewares/logger.js、utils/response.js |
| HTTPS | 生产环境强制使用 HTTPS | 服务器配置 |
| 邮箱验证码 | Redis 存储 + 过期时间 + 冷却期 | controllers/authController.js、services/emailService.js |

## 8. 可扩展性与维护建议

### 8.1 纵向扩展点

| 功能领域 | 扩展方式 |
|----------|----------|
| 物品分类 | 目前使用字符串分类，可新增分类表与分类管理页面 |
| 搜索 | 目前使用 SQL LIKE，后续可接入 Elasticsearch |
| 图片存储 | 目前本地文件系统，后续可平滑迁移到对象存储（COS/OSS/七牛） |
| 推送 | 目前依赖通知表和用户主动拉取，可接入微信订阅消息 |
| 消息 | 目前轮询拉取，可升级为 WebSocket 实时推送 |

### 8.2 横向扩展点

- **应用服务器**：部署多实例 + Nginx 负载均衡
- **数据库**：读写分离（主库写、从库读）
- **缓存**：Redis 集群部署，分离会话、验证码、限流数据
- **CDN**：静态资源与用户上传图片走 CDN，减轻服务器压力

### 8.3 监控与运维建议

- **日志**：已使用 winston 结构化输出，建议接入 ELK / Loki
- **错误告警**：5xx 错误阈值触发告警
- **性能指标**：关注接口 P95 响应时间、QPS、并发连接数
- **备份策略**：MySQL 定期全量+增量备份，Redis AOF 持久化
- **敏感数据**：邮箱、手机号在展示层脱敏
