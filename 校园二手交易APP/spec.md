# 校园二手交易APP需求规格说明书

## 1. 项目概述

### 1.1 项目背景
随着校园二手交易市场的日益活跃，学生们需要一个安全、便捷的平台来买卖二手物品。当前市场上的交易平台存在信息不对称、交易安全性低、功能单一等问题，无法满足校园用户的特殊需求。本项目旨在开发一个专为校园师生设计的二手交易APP，提供安全、便捷、高效的交易服务。

### 1.2 项目目标
- 为校园师生提供一个安全、便捷的二手交易平台
- 支持商品发布、浏览、搜索、购买等核心功能
- 提供实时聊天、订单管理、收藏夹等辅助功能
- 实现管理后台，便于管理人员审核商品、处理举报
- 确保平台的安全性、稳定性和用户体验

### 1.3 适用范围
本项目适用于大学校园师生，支持Android客户端和Web管理后台。

## 4. 技术架构

### 4.1 前端技术栈（Android）
- **开发语言**：Dart
- **框架**：Flutter 3.x
- **状态管理**：Riverpod
- **路由管理**：GoRouter
- **网络请求**：Dio
- **UI组件库**：Material Design

### 4.2 后端技术栈（Spring Boot 3.x）
- **开发语言**：Java 17
- **框架**：Spring Boot 3.2.4
- **数据库**：MySQL 8.0+
- **ORM框架**：Spring Data JPA
- **安全框架**：Spring Security 6.x
- **API文档**：Swagger/OpenAPI 3
- **文件存储**：本地文件系统
- **WebSocket**：Spring WebSocket

### 4.3 系统架构
```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│   Flutter客户端  │ ←→ │   Spring Boot    │ ←→ │      MySQL      │
│                 │    │     后端API       │    │                 │
│ - Riverpod状态管理  │    │ - RESTful API    │    │ - 关系型数据库    │
│ - GoRouter路由管理  │    │ - WebSocket服务   │    │ - 事务支持       │
│ - Dio网络请求     │    │ - 业务逻辑处理    │    │ - 索引优化       │
│ - Material Design UI │  │ - 数据库操作      │    │ - 数据备份       │
└─────────────────┘    └──────────────────┘    └─────────────────┘
```

## 5. 数据库设计

### 5.1 核心实体

- id: 主键

- password: 密码（加密）
- email: 邮箱
- phone: 手机号
- role: 角色
- avatar: 头像URL
- real_name: 真实姓名
- school: 学校
- status: 状态
- create_time: 创建时间
- update_time: 更新时间

#### 5.1.2 商品表 (products)
- id: 主键
- title: 商品标题
- price: 价格

- category: 分类
- seller_id: 卖家ID
- images: 图片URL列表
- location: 交易地点
- contact_info: 联系方式
- status: 状态（ON_SALE/OFF_SALE/SOLD/DELETED）
- audit_status: 审核状态（PENDING/APPROVED/REJECTED）
- view_count: 浏览量
- like_count: 点赞量
- create_time: 创建时间
- update_time: 更新时间

#### 5.1.3 订单表 (orders)
- id: 主键
- order_no: 订单号
- buyer_id: 买家ID
- seller_id: 卖家ID
- product_id: 商品ID
- price: 价格
- quantity: 数量
- total_price: 总价
- status: 状态
- address_id: 收货地址ID
- note: 备注
- payment_method: 支付方式
- payment_time: 支付时间
- delivery_time: 发货时间
- receive_time: 收货时间
- create_time: 创建时间
- update_time: 更新时间

#### 5.1.4 消息表 (messages)
- id: 主键
- sender_id: 发送者ID
- receiver_id: 接收者ID
- content: 消息内容
- type: 消息类型（TEXT/IMAGE）
- read_status: 已读状态
- create_time: 创建时间

#### 5.1.5 举报表 (reports)
- id: 主键
- reporter_id: 举报者ID
- target_id: 被举报对象ID
- target_type: 被举报对象类型（PRODUCT/USER/ORDER/MESSAGE）
- reason: 举报原因
- description: 举报描述
- evidence_urls: 证据URL列表
- status: 状态（PENDING/IN_PROGRESS/RESOLVED/REJECTED）
- handled_by: 处理人ID
- handled_time: 处理时间
- resolution: 处理结果
- auto_flagged: 是否自动标记
- auto_reason: 自动标记原因
- create_time: 创建时间
- update_time: 更新时间

#### 5.1.6 购物车表 (cart_items)
- id: 主键
- user_id: 用户ID
- product_id: 商品ID
- quantity: 数量
- create_time: 创建时间
- update_time: 更新时间

#### 5.1.7 收藏表 (favorites)
- id: 主键
- user_id: 用户ID
- product_id: 商品ID
- create_time: 创建时间

#### 5.1.8 地址表 (user_addresses)
- id: 主键
- user_id: 用户ID
- name: 收货人姓名
- phone: 联系电话
- province: 省份
- city: 城市
- district: 区县
- detail: 详细地址
- is_default: 是否默认地址
- create_time: 创建时间
- update_time: 更新时间
