## 2. API设计

### 2.1 RESTful API

| 接口名称 | 请求方法 | 路径 | 描述 |
|---------|---------|------|------|
| 获取对话列表 | GET | /api/v1/conversations | 获取用户的对话列表 |
| 获取聊天历史 | GET | /api/v1/conversations/{id}/messages | 获取指定对话的聊天历史 |
| 发送消息 | POST | /api/v1/messages | 发送一条新消息 |
| 标记消息已读 | PUT | /api/v1/messages/read | 标记消息为已读 |
| 删除对话 | DELETE | /api/v1/conversations/{id} | 删除指定对话 |
| 获取未读消息数 | GET | /api/v1/messages/unread | 获取用户的未读消息数 |

### 2.2 WebSocket API

| 事件名称 | 方向 | 描述 |
|---------|------|------|
| MESSAGE_CREATED | 服务器→客户端 | 新消息创建事件 |
| MESSAGES_READ | 服务器→客户端 | 消息已读事件 |
| CONVERSATION_UPDATED | 服务器→客户端 | 对话更新事件 |
| MESSAGE_SENT | 客户端→服务器 | 发送消息事件 |
| MARK_READ | 客户端→服务器 | 标记已读事件 |
| JOIN_CONVERSATION | 客户端→服务器 | 加入对话事件 |

## 3. 数据库设计

### 3.1 消息表 (messages)

| 字段名 | 类型 | 描述 |
|---------|------|------|
| id | BIGINT | 消息ID |
| conversation_id | BIGINT | 所属对话ID |
| sender_id | BIGINT | 发送者ID |
| receiver_id | BIGINT | 接收者ID |
| content | TEXT | 消息内容 |
| message_type | VARCHAR(20) | 消息类型 (TEXT/IMAGE/AUDIO/FILE) |
| attachment_url | VARCHAR(255) | 附件URL |
| is_read | BOOLEAN | 是否已读 |
| read_time | DATETIME | 已读时间 |
| create_time | DATETIME | 创建时间 |
| update_time | DATETIME | 更新时间 |

### 3.2 对话表 (conversations)

| 字段名 | 类型 | 描述 |
|---------|------|------|
| id | BIGINT | 对话ID |
| user1_id | BIGINT | 用户1 ID |
| user2_id | BIGINT | 用户2 ID |
| last_message_id | BIGINT | 最后一条消息ID |
| unread_count | INT | 未读消息数 |
| related_type | VARCHAR(20) | 关联类型 (PRODUCT/ORDER) |
| related_id | BIGINT | 关联ID |
| create_time | DATETIME | 创建时间 |
| update_time | DATETIME | 更新时间 |

## 4. 前端实现

### 4.1 聊天列表页面

- 显示用户的对话列表
- 显示每个对话的最后一条消息
- 显示未读消息数
- 支持下拉刷新
- 支持点击进入聊天详情页面

### 4.2 聊天详情页面

- 显示聊天历史记录
- 支持发送文本、图片、语音消息
- 支持消息已读状态显示
- 支持滚动加载历史消息
- 支持消息发送状态显示

### 4.3 状态管理

- 使用 Riverpod 进行状态管理
- 维护对话列表状态
- 维护聊天历史状态
- 维护消息发送状态
- 支持 WebSocket 事件处理

## 5. 后端实现

### 5.1 消息服务

- 处理消息的发送、接收和存储
- 处理对话的创建和管理
- 处理消息的已读状态
- 处理消息的推送

### 5.2 WebSocket服务

- 管理 WebSocket 连接
- 处理消息的推送
- 处理客户端的事件
- 支持心跳检测

### 5.3 消息推送服务

- 支持多种推送方式
- 支持消息的批量推送
- 支持消息的优先级
- 支持消息的重试机制
