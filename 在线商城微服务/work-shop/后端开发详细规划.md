# 在线商城系统 - 后端开发详细规划

## 1. 项目概述

### 1.1 项目背景

基于微服务架构的在线商城系统，面向普通用户提供商品浏览、选购、加购、下单、支付、评价、收藏等全流程电商能力。系统采用微服务拆分，保证高可用、易扩展、分布式事务安全，满足多用户并发访问与库存一致性要求。

### 1.2 核心功能

- 商品选购（实时库存）
- 购物车（增删改数量、自动计价）
- 订单创建 + 库存扣减（分布式事务一致性）
- 附加功能：商品收藏、商品评价、个人中心

### 1.3 技术栈

- **前端**：Vue 3 + Vite + Tailwind CSS + Pinia + Vue Router
- **网关层**：Nginx + Spring Cloud Gateway
- **微服务**：Spring Boot + Spring Cloud Alibaba
- **注册与配置中心**：Nacos
- **分布式事务**：Seata（AT 模式）
- **数据库**：MySQL（业务库）
- **缓存**：Redis
- **日志与链路**：ELK 或 Loki + Promtail + Grafana，Sleuth/Zipkin（可选）

## 2. 微服务架构设计

### 2.1 微服务拆分

| 服务名称                 | 功能职责            | 核心接口               | 所属域 |
| -------------------- | --------------- | ------------------ | --- |
| **gateway-service**  | 统一入口、鉴权、限流、灰度路由 | `/api/**`          | 网关层 |
| **user-service**     | 注册、登录、用户信息、地址管理 | `/api/user/**`     | 用户域 |
| **product-service**  | 商品列表、详情、分类、搜索   | `/api/product/**`  | 商品域 |
| **stock-service**    | 库存查询、扣减、回滚      | `/api/stock/**`    | 商品域 |
| **cart-service**     | 购物车增删改查、金额计算    | `/api/cart/**`     | 交易域 |
| **order-service**    | 下单、订单状态流转、支付模拟  | `/api/order/**`    | 交易域 |
| **favorite-service** | 收藏/取消收藏         | `/api/favorite/**` | 运营域 |
| **review-service**   | 评价发布/查询         | `/api/review/**`   | 运营域 |
| **profile-service**  | 个人中心聚合查询        | `/api/profile/**`  | 用户域 |

### 2.2 分层架构

1. **接入层**：Web 前端 + Nginx
2. **网关层**：API Gateway（鉴权、路由、限流）
3. **业务层**：各业务微服务（高内聚低耦合）
4. **基础设施层**：Nacos、Seata、Redis、日志平台
5. **数据层**：MySQL（按服务分库分表预留）

## 6. 技术实现要点

### 6.1 分布式事务实现

- 使用 Seata AT 模式
- 订单服务作为全局事务发起者
- 库存服务和购物车服务作为参与者
- 事务传播机制：REQUIRED

### 6.2 库存防超卖

- 乐观锁：使用 version 字段
- Redis 预扣库存
- 库存校验：下单前和扣减时双重校验

### 6.3 缓存策略

- 商品信息缓存：Redis
- 库存缓存：Redis，实时更新
- 热点数据缓存：用户信息、商品分类

### 6.4 安全措施

- JWT 认证
- 密码 BCrypt 加密
- 防 SQL 注入
- 防 XSS 攻击
- 接口限流
- 敏感信息脱敏

### 6.5 性能优化

## 9. 风险与应对

### 9.1 风险识别

1. **高并发超卖**
2. **分布式事务性能开销**
3. **服务雪崩**
4. **敏感信息泄露**
5. **数据库性能瓶颈**
6. **缓存一致性**

### 9.2 应对策略

1. **高并发超卖**
   - 乐观锁 + Redis 预扣 + Seata 回滚兜底
   - 库存校验双层保障
2. **分布式事务性能开销**
   - 仅在核心链路启用全局事务
   - 减少事务范围
   - 异步处理非核心操作
3. **服务雪崩**
   - 网关限流
   - 熔断降级
   - 超时重试
   - 隔离舱模式
4. **敏感信息泄露**
   - 生产环境使用配置中心加密
   - 不明文存储数据库密码
   - 敏感数据传输加密
5. **数据库性能瓶颈**
   - 合理索引设计
   - 分库分表预留
   - 读写分离
   - 连接池优化
6. **缓存一致性**
   - 双写一致性
   - 缓存过期策略
   - 异步更新缓存
