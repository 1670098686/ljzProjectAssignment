一、基础部署规则
1.  部署环境：需搭建稳定的服务器环境，确保服务器可正常访问公网，且已安装对应版本的Nginx服务，避免因环境不兼容导致网页无法正常启动。
2.  网页文件放置：将在线商城的前端网页文件（含页面、样式、静态资源等）统一放置在Nginx指定的根目录下，目录路径需清晰可查，便于后续维护和更新。
3.  配置文件规范：Nginx配置文件需单独存放，命名规范统一（如mall-nginx.conf），配置内容需完整，包含端口、根目录、路由等核心配置，避免冗余无效配置。
4.  启动与重启：启动Nginx服务前需检查配置文件正确性，确认无误后启动；后续修改配置文件后，需重启Nginx服务，确保配置生效，重启过程中需避免影响用户正常访问。
二、网页访问规则
1.  端口设置：统一使用80端口作为网页默认访问端口，若80端口被占用，需提前调整端口，并在配置文件中明确声明，同时告知用户访问端口。
2.  访问路径：用户通过服务器IP或绑定的域名即可访问在线商城网页，无需额外输入路径，确保访问路径简洁，符合用户使用习惯。
3.  页面跳转：网页内部跳转需流畅，点击导航、商品、按钮等元素时，跳转路径正确，无404、500等错误页面，跳转速度控制在合理范围内。
4.  静态资源访问：网页中的图片、样式、脚本等静态资源，需确保访问路径正确，无资源加载失败的情况，提升用户浏览体验。
三、安全访问规则
1.  身份校验：通过Nginx配置，限制未登录用户访问个人中心、订单管理、收藏等核心页面，跳转至登录页面，确保用户信息安全。
2.  防恶意访问：配置Nginx限流规则，限制单IP单位时间内的访问次数，防止恶意刷单、恶意请求导致服务器负载过高。
3.  页面安全：禁止直接访问网页后台文件、配置文件等敏感资源，通过Nginx拦截非法访问请求，返回错误提示。
4.  数据传输：若涉及用户登录、支付等敏感操作，需配置HTTPS协议，确保数据传输过程加密，防止数据泄露。
四、维护与更新规则
1.  备份规则：定期备份Nginx配置文件和网页文件，备份文件需分类存放，标注备份时间，便于出现问题时快速恢复。
2.  更新规则：更新网页文件时，需先将旧文件备份，再替换新文件，替换完成后重启Nginx服务，确保更新后网页正常运行，无兼容性问题。
3.  日志管理：开启Nginx访问日志和错误日志，日志文件需定期清理，保留一定周期的日志，便于排查网页访问异常、错误等问题。
4.  异常处理：若网页出现无法访问、加载失败等异常，需先检查Nginx服务状态和配置文件，再排查网页文件和服务器环境，及时处理并记录异常原因及解决方法。
五、兼容性与易用性规则
1.  浏览器兼容：网页需兼容主流浏览器（Chrome、Edge、Firefox等），确保在不同浏览器中页面布局、功能正常，无错乱、无法操作等问题。
2.  设备兼容：支持PC端、移动端（手机、平板）访问，页面可自适应不同设备屏幕尺寸，确保移动端用户浏览和操作体验良好。
3.  易用性要求：网页导航清晰，按钮、文案简洁明了，操作流程符合电商用户使用习惯，减少用户理解和操作成本，错误提示明确，引导用户正确操作。
六、关联微服务规则
1.  路由转发：通过Nginx配置路由规则，将网页的请求（商品查询、订单提交、收藏等）正确转发至对应的微服务，确保请求响应及时、准确。
2.  服务容错：配置Nginx反向代理和容错机制，当某个微服务出现故障时，避免网页直接报错，返回友好提示，同时不影响其他功能正常使用。
3.  负载均衡：若微服务采用集群部署，通过Nginx配置负载均衡规则，将网页请求均匀分配至各个微服务节点，提升系统并发处理能力，避免单个节点负载过高。
