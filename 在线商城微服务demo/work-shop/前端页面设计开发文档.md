# 在线商城系统 - 前端页面设计开发文档

## 一、设计概述

### 1.1 设计理念
- **简约现代**：采用扁平化设计风格，去除多余装饰，突出内容本身
- **用户友好**：操作流程符合电商用户习惯，减少学习成本
- **响应式布局**：优先保障PC端体验，同时支持移动端适配
- **一致性**：所有页面采用统一的设计语言和交互模式

### 1.2 技术栈
- **框架**：Vue 3 + Vite
- **样式**：Tailwind CSS 3.x
- **状态管理**：Pinia
- **路由**：Vue Router 4
- **HTTP客户端**：Axios
- **开发服务器**：http://localhost:8080

### 3.2 Header 导航栏

#### 结构
```
[Logo] [搜索框] [购物车(带数量)] [用户中心/登录]
```

#### 设计规范
- 高度：64px
- 背景：白色
- 阴影：shadow-sm
- 固定在顶部：`position: sticky; top: 0; z-index: 50;`

#### Logo 区域
- 宽度：120px
- 图标：购物车图标 + "在线商城"文字
- 颜色：主色渐变 (#6366f1 → #8b5cf6)

#### 搜索框
- 宽度：400px (最小 280px)
- 高度：40px
- 圆角：lg (12px)
- 边框：border-2 border-gray-200
- 聚焦状态：border-indigo-400, ring-4 ring-indigo-100

#### 购物车按钮
- 图标 + 数量角标
- 角标背景：主色，白色文字
- 悬停：背景色变化

#### 用户中心
- 未登录：显示"登录/注册"按钮
- 已登录：显示用户头像/昵称 + 下拉菜单

### 3.3 Main Content 主内容区

- 最大宽度：1280px
- 居中对齐：`margin: 0 auto;`
- 水平内边距：24px
- 顶部内边距：32px

### 3.4 Footer 页脚

- 背景：#1e293b (Slate 800)
- 文字：白色
- 高度：80px
- 内容：版权信息 + 快速链接
